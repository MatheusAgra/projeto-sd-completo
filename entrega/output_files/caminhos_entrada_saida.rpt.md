# caminhos_entrada_saida.rpt

Relatório nativo TimeQuest de vinte caminhos entre entradas e saídas. Na revisão final, o maior atraso reportado é 23,788 ns, SW[5]→HEX0[1], modelo Slow 1200mV 85C, onze níveis lógicos. Não é uma medição física nem aprovação contra orçamento temporal: o enunciado não define tal orçamento. O script `relatar_caminhos.tcl` produz o relatório sem inventar clocks ou SDC.
