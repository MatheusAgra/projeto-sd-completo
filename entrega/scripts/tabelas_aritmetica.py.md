# tabelas_aritmetica.py

Gera CSVs das tabelas completas do somador de um bit e dos conversores SM/C2 e negador, além de mapas de Karnaugh e diagramas das cadeias aritméticas em `docs/tabelas/aritmetica`. Não gera nem modifica os BDF. As tabelas descrevem funções matemáticas; a verificação da implementação usa os testbenches independentes executados sobre a exportação nativa do Quartus. Execute com Python 3 a partir de qualquer pasta.
